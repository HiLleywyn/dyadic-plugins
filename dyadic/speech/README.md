Read an answer or any text aloud as an audio file you can play.

**Version:** 1.0.0. **Native tool switch:** `audio.speak`.

[plugin.json](plugin.json) is an unmodified official catalog descriptor from Dyadic `26ea591af225ed48129a1968db78b3e8f335dc90`, `catalog/plugins/speech`. Aliases: none.

## Capabilities declared by the source

- Reads an answer or any text aloud
- Keeps the audio in your Workspace files

## Permissions declared by the source

- Sends the text to the speech model
- Uses credits for each clip

This folder contains the Store descriptor, not the server implementation, provider sign-in or an executable plugin installer. The built-in runtime and account configuration must already provide the named switch. Publishing or downloading this folder does not turn it on. See [runtime compatibility](../../COMPATIBILITY.md).
