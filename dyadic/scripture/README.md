Commercially reusable Bible translations, books and verse-preserving chapter reads through Free Use Bible API.

**Version:** 1.0.0. **Native tool switch:** `religion.*`.

[plugin.json](plugin.json) is an unmodified official catalog descriptor from Dyadic `26ea591af225ed48129a1968db78b3e8f335dc90`, `catalog/plugins/scripture`. Aliases: religion, bible, scripture.

## Capabilities declared by the source

- License-filtered translation discovery
- Book and chapter references with verse numbers and attribution

## Permissions declared by the source

- Read-only public text; per-translation licenses apply
- Unknown, non-commercial and no-derivatives licenses are excluded; no Quran Foundation redistribution

This folder contains the Store descriptor, not the server implementation, provider sign-in or an executable plugin installer. The built-in runtime and account configuration must already provide the named switch. Publishing or downloading this folder does not turn it on. See [runtime compatibility](../../COMPATIBILITY.md).
