Find NASA media, astronomy pictures and upcoming space launches.

**Version:** 1.0.0. **Native tool switch:** `space.*`.

[plugin.json](plugin.json) is an unmodified official catalog descriptor from Dyadic `26ea591af225ed48129a1968db78b3e8f335dc90`, `catalog/plugins/space`. Aliases: space.

## Capabilities declared by the source

- Search NASA media with source credits
- Discover provisional launch schedules
- Read astronomy pictures through NASA Science APOD

## Permissions declared by the source

- Sends requested space topics to the selected provider
- Media copyright and provider quotas still apply

This folder contains the Store descriptor, not the server implementation, provider sign-in or an executable plugin installer. The built-in runtime and account configuration must already provide the named switch. Publishing or downloading this folder does not turn it on. See [runtime compatibility](../../COMPATIBILITY.md).
