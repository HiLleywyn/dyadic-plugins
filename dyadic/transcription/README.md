Write down what an audio file you attach says.

**Version:** 1.0.0. **Native tool switch:** `audio.transcribe`.

[plugin.json](plugin.json) is an unmodified official catalog descriptor from Dyadic `26ea591af225ed48129a1968db78b3e8f335dc90`, `catalog/plugins/transcription`. Aliases: none.

## Capabilities declared by the source

- Writes down what an audio file you attach says
- Works with MP3, WAV, M4A, OGG, WebM and FLAC

## Permissions declared by the source

- Sends the audio to the transcription model
- Uses credits by the minute of audio

This folder contains the Store descriptor, not the server implementation, provider sign-in or an executable plugin installer. The built-in runtime and account configuration must already provide the named switch. Publishing or downloading this folder does not turn it on. See [runtime compatibility](../../COMPATIBILITY.md).
